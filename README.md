`main.py` (Python, standard library only) writes one sentence to `/output/entry.txt`:

> ChirpAlert texts you the instant a bird within 500 metres chirps, because in a world full of noise, no chirp should ever go unnoticed.

ChirpAlert: a real-time alert for a problem nobody has ever had — missing a bird chirp — pitched with the deadpan certainty of a founder who means every word.
